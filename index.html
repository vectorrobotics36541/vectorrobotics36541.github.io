Mission

Two components,
one team.

In physics a vector needs both a size and a direction to mean anything. We built the team the same way — the discipline to build well, aimed at a reason worth building for.

x̂ Magnitude

Engineering,
done rigorously

CAD before fabrication. Test logs before competition. We document every iteration — failures included — in a real engineering notebook.

ŷ Direction

STEM,
pointed outward

We compete to get better at building things, but we exist to bring more people into STEM — outreach, mentorship, and a program built to outlast any one season.
